# Asus\_ZenBook\_UX425EA-KI499T\_hackintosh

A successful attempt to hackintosh this ZenBook.

Monterey was installed, then upgraded to Sequoia.

Make sure VMD, VT-d, Fast Boot and Secure Boot are disabled at the BIOS.

Need the HeliPort app for WiFi support on Sequoia.

For WiFi support on Monterey need to replace the itlwm kext with the AirportItlwm kext.
